# DuuniExpo Passi 2027 Front End

Tämä on vaan näytille, kehitys jatkuu siellä uudessa projektissa sitten.

Kryptisiä api endpointteja / logiikkaa ym. muutakin toiminnallisuutta voisi pilkkoa ja jakaa omiksi palasiksiin

Tässä on aika paljon spagettia, prop drillattuja callbackeja ja siellä täällä isoja saavutettavuusongelmia, joiden fiksaaminen on nyt syksyllä muun kehityksen rinnalla agendalla.

## Svelte + Vite

Käynnistys:

`npm install`

`npm run dev`
